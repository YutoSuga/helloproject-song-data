# 公開サイトデータ生成・ビルド仕様

> 2026-11-25 運用切替：全生成入口はFN-004非依存の共通readerで全14表を検証します。通常CIは一本化、Gate/FN-004試験は保存版手動CIへ分離済みです。以下の旧light/full・Gate依存の記述は移行前の参照で、現行挙動は.github/CI.mdを正とします。

## 適用範囲と正本

公開サイト全体の生成呼出・成果物整合性・公開を扱うFN番号を持たない共通仕様。ランキングの規則は[FN-001](../functions/FN-001-ランキング集計仕様.md)、楽曲一覧生成は[FN-005](../functions/FN-005-楽曲一覧データ生成.md)、表示は[公開サイト共通設計](../screens/公開サイト共通設計.md)を正本とする。

楽曲などの正本は `data/*.csv` とし、再生成可能な派生JSONをGit管理する。SCR-002の更新履歴・収録状況・説明文は別に手動管理する。運用は[その他・サイト情報](../screens/public/SCR-002-その他・サイト情報.md)を参照。FN-004による安全なcanonical反映と、このビルド・公開運用は別の責務である。

### 現在実装済み

[package.json](../../../package.json)の`npm run site:build`は`npm run rankings:generate`、`npm run songs:generate`、`node scripts/build-about-data.js`を順に実行する。最後の処理で手動JSONを検証し、アーティスト名と登録音源数を出力する。`site/`の静的ファイルと生成JSONが公開artifactになる。ローカル・CIで同じコマンドを使う。artist引数とランキング固有検証はFN-001を参照する。

### FN-005の接続

`site:build`からFN-001とFN-005の独立した生成CLIを順に呼ぶ。各機能が結合・導出・出力形式を保証し、共通ビルドは呼出と全体の成否を管理する。いずれかの非0終了でbuild失敗。`songs:validate`は厳密なJSON契約と画面の消費形式、canonical再生成一致を検査する。

## 生成物の整合性

ローカルでcanonical更新後に再生成し、内容をレビューしてCSVと生成JSONをcommitする。CIも同じ入力・方式で再生成し、commit済みJSONとの一致を検査する。CIは生成結果を自動commit/pushしない。

`npm run site:check-generated`はsite/data/rankings・site/data/songs・site/data/about/artists.jsonを対象に、`git diff --exit-code HEAD -- <対象パス>`で追跡済み差分（stagedも含む）、`git ls-files --others -z -- <対象パス>`で未追跡出力を検出する。ignoreに一致した新規出力も除外しない。差分・削除・追加ファイルのcommit漏れはいずれも非0終了。ローカルではJSONをcommitした後に実行する。

## CI失敗条件・GitHub Pages公開条件（現行）

挙動の正本は[workflow](../../../.github/workflows/deploy-pages.yml)、[ID比較境界](../../../.github/scripts/id-ci-base.cjs)、[CI運用ルール](../../../.github/CI.md)。

- 通常buildは全14表検証、ID差分検証、全通常suite、ランキング・楽曲検証、site:build、生成物一致検査を毎回実行する。非0終了で失敗する。
- PRでは検証のみ。mainのbuild成功時だけsite artifactを作成し、Deployへ渡す。
- Deployは通常build成功を前提とし、公開lock内で最新main SHAと一致するartifactのみ公開する。古いSHAはskip、API照会失敗は停止する。
- 旧ci-policy.cjsによるlight/full選択とGate依存は移行前の方式。保存版FN-004試験は固定保存SHAを使う手動workflowに分離し、通常Deployの依存には含めない。

## JOB-001・ブラウザとの境界

JOB-001はFN-002の候補収集を定期起動する未実装ジョブであり、公開CIの別名ではない。候補の確認・FN-004反映を自動確定しない。公開CIはcanonicalから派生物を検証・生成・公開する既存運用である。

ブラウザは生成JSONを読み、画面側の形式確認・検索・並び替え・表示・読込エラー処理を行う。CSV結合・参照整合性・日付導出はFN-005、ランキング集計はFN-001が担当する。生成JSONと画面の契約整合性はCIで自動検証する設計とし、楽曲分はsongs:validateと契約テストで実装済み。
