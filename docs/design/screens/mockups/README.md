## 開き方

このディレクトリ全体を保持し、index.htmlをローカルPCのブラウザで直接開く。サーバーは不要。5ページの相対リンク、CSS、通常scriptだけを使用しCSV・JSON・APIを取得しない。全値はHTMLに記載したレビュー用仮データであり、本番値の確定情報ではない。仮IDも本番採番に使わない。

- [ホーム](index.html) ↔ [設計書](../public/SCR-001-ホーム.md)
- [楽曲](songs.html) ↔ [設計書](../public/SCR-003-楽曲一覧・検索.md)
- [動画](videos.html) ↔ [設計書](../public/SCR-007-動画一覧.md)
- [作家](creators.html) ↔ [設計書](../public/SCR-005-作家一覧・ランキング.md)
- [その他](more.html) ↔ [設計書](../public/SCR-002-その他・サイト情報.md)

CSSはレビュー番号をdata-item-noから生成。項目IDはdata-item-id、番号は設計書No.に対応。共通C番号と画面内番号は別名前空間。反復カードは代表構造に付番し、同構造の他行は番号を省略する。R-01は状態レビュー専用で本番に置かない。

## 操作確認

作家の5カテゴリ、曲数／組み合わせ分析、方向・作家候補の選択、検索で候補なし、自己作品数、集計根拠ボタン、閉じる／Escapeを試す。根拠行は代表構造の仮値を表示するため、ダイアログ内の行数はカード作品数を再現しない。カテゴリごとの件数もHTMLのdata-countsに置いた仮値。
楽曲・作家のR-01で正常／読込中／空／失敗、作家では組合せ未生成を再現する。再読込で初期状態へ戻る。楽曲検索・絞り込みの採否は未確定で、楽曲モックは一覧のみ。

## 未確認・限界

管理ブラウザがfile://をERR_BLOCKED_BY_ADMINISTRATORで拒否したため、ファイル直接閲覧のブラウザ操作は未確認。相対リンク・通常script・通信なしの構造は静的確認し、同じファイルをHTTPで操作した。ユーザーのローカルPCで直接閲覧を確認する。HTTPサーバーは成果物の要件ではない。
iPhone実機のsafe-area、実機タップ、スクリーンリーダー、全ブラウザの見た目は未確認。スクリーンショットは生成・登録していない。ブラウザ検査は寸法と操作の確認で、全要素の目視評価ではない。

## 公開・後続実装

これは設計レビュー用で本番へのコピーを前提としない。配置はdocs/design/screens/mockups、Pages artifactはsite/のみ。公開コード・canonical・FN-004・集計処理の変更は別タスク。楽曲検索の採否、生成方式、実装PR分割は設計レビュー後に判断する。Ready for Reviewへの変更・マージはユーザー承認なしに行わない。
