## 現行レイアウト・レビュー手順

- ホームはタイトル→アーティスト欄→固有内容。PC本文幅960px以上で4列2行、狭いPCとSPは2列4行。PCサイドバーにはサイト名・5ナビのみ。
- 楽曲・動画・作家はPC/SPとも同じコンパクトな1行横スクロール。最小ボタン高さ44px（ホーム64px）、間隔10px（ホーム横12px/縦22px）、上ラベルを含む内部余白を確保。Juice=Juiceを初期可視にする。
- その他とデータについてではアーティスト欄をDOMから省略。その他はタイトル→サイト概要→データについてへのリンク→免責→連絡先・X。移動前後も今回はJuice=Juice固定。将来の状態保持は共通設計参照、方式未定・実装なし。
- 楽曲はwork単位。検索・3並び順、音源初出日/確認中表示、4音源詳細の×/Escapeを確認。作家は5カテゴリ、方向・単一コンボ入力/候補選択・根拠の名前クリックを確認。既存機能・JSON契約・確定文言は今回変更しない。
- ホームに仮の更新履歴を3件、データについてに同じ履歴を含む仮の全4件と、収録済み・確認中・未収録の例を表示する。
- 楽曲・作家のR-01で正常/空/読込中/失敗、番号チェックで表示ON/OFF。仮データ・レビュー専用操作を本番には持ち込まない。
