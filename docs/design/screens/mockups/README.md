## 開き方・成果物

ディレクトリ全体を保持してindex.htmlをローカルPCのブラウザで直接開く構成。サーバー必須ではない。相対HTMLリンク、ローカルCSS、通常scriptだけを使用しCSV/JSON/APIを取得しない。全データはHTML（data属性・templateを含む）に置いた仮値。確定値・本番IDとして使用しない。

「項目番号を表示」で番号と通常表示を切り替える。No.=data-item-no、項目ID=data-item-id。共通C番号とページ内番号は別名前空間。繰返すカード・音源・候補は代表構造の項目パスを用い、DOM idは重複させない。R-01と番号スイッチはレビュー専用で本番に置かない。

## 現行レイアウト・レビュー手順

- ホームはタイトル→アーティスト欄→固有内容。PC本文幅960px以上で4列2行、狭いPCとSPは2列4行。PCサイドバーにはサイト名・5ナビのみ。
- 楽曲・動画・作家はPC/SPとも同じコンパクトな1行横スクロール。最小ボタン高さ44px（ホーム64px）、間隔10px（ホーム横12px/縦22px）、上ラベルを含む内部余白を確保。Juice=Juiceを初期可視にする。
- その他ではアーティスト欄をDOMから省略。タイトル→サイト情報・免責→連絡先・X。移動前後も今回はJuice=Juice固定。将来の状態保持は共通設計参照、方式未定・実装なし。
- 楽曲はwork単位。検索・3並び順、日付欄非表示の規則、2音源詳細の×/Escapeを確認。作家は5カテゴリ、方向・単一コンボ入力/候補選択・根拠の名前クリックを確認。既存機能・JSON契約・確定文言は今回変更しない。
- R-01で正常/空/読込中/失敗、番号チェックで表示ON/OFF。仮データ・レビュー専用操作を本番には持ち込まない。

## 今回実施した検証（2026-11-22 JST）

Linux Chromium headless、同じファイルをlocalhost HTTPで配信。

- 320/375/390/768/1024/1440px × 5ページ＝30組を検査。1440pxホームは4列2行、他の指定幅は2列4行。全4画面でタイトル直下に欄、サイドバー内には0、その他は欄もC-08〜15も0。
- 楽曲/動画/作家は全幅でoverflow領域があり、選択中が初期可視。ボタン最小44pxかつホーム64px未満、非活性7/選択1・8組の順序と色を維持。全Coming Soonラベルの四辺とグループ名との縦方向非重複を寸法検査。ページ全体の横はみ出しなし。
- 領域フォーカス＋ArrowRight、水平wheelイベント、CDP touchStart/move/endのタッチスワイプで横スクロールを確認。これらはエミュレーションであり物理トラックパッド等の実機検証ではない。
- 既存楽曲検索の複数語/空/0件・古い順/曲名順、2音源詳細×/Escape/起点復帰、作家5カテゴリ・名前クリック・コンボ両方向の入力/矢印/Enter・0候補/無効入力/結果保持/Escape、読込状態を回帰検証。JavaScriptエラー・外部通信なし。
- MarkdownのNo./項目IDとHTML代表構造、ローカルリンク、DOM idを機械照合。共通アーティストC-08〜15はその他で適用対象外と明記。node --check、git diff --check、rankings:validate、既存ランキング関連3テストファイル成功。
- 変更は設計書・モックのみ。site/・canonical・FN-004・ランキング処理・workflow変更なし。Pages artifactはsite/のみで設計モックを含まない。
