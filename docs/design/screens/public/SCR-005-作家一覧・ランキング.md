# SCR-005 ランキング

[共通設計](../公開サイト共通設計.md)・[FN-001](../../functions/FN-001-ランキング集計仕様.md)・[HTMLモック](../mockups/creators.html)

共通アーティスト選択の下に、すべて（初期）、作詞、作曲、作詞 & 作曲、編曲の順でカテゴリを並べる。選択カテゴリの作家数、延べ担当曲数（各行の合計）、順位、作家名、担当曲数を表示。作家名からSCR-006へ遷移し、戻ると元カテゴリ・スクロールを復元する。集計・競技順位・同順位内の作家ID順は既存JSONを使用する。作家検索はSCR-003、組み合わせはSCR-009で表示する。
