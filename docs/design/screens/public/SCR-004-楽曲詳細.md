# SCR-004 楽曲詳細

[共通設計](../公開サイト共通設計.md)・[HTMLモック](../mockups/song-detail.html)

`songs/<artist_id>.json` の `works` からWork IDで1件を引く。見出しはWorkの代表タイトルと対象アーティスト名。音源初出日は `first_release_date`（対象artistがprimaryのAudioのうち既知の最小日）、nullは「確認中」。`date_incomplete` かつ既知日ありの場合は一部音源の日付未確認を併記する。音源数は `songs.length`、担当作家数は全Songのcreditsにある異なる `creator_id` の数。同じ作家の複数役割・音源を重複加算しない。

Songを既知日昇順・不明末尾・同日ID順に並べる。音源名・バージョン名（存在時）と種別・当該音源の発売日を表示。1音源ではメタ情報と担当作家を直接表示し、複数音源では見出しと区切り線を使い、各音源の情報を初期状態で展開する。各音源で担当を作詞、作曲、編曲、英語詞、ブラス編曲の順に示す。役割内はcredit_order昇順、未指定末尾、同順位はcreator_id順。表示は掲載名義（正規名と異なる場合は補記）、リンクIDはcreator_id。クレジット欠損は未確認として扱う。関連する作家へのリンクは対象artistを維持する。Workの存在、音源アンカーの所有、読み込み状態は共通設計に従う。
