# SCR-009 分析

[共通設計](../公開サイト共通設計.md)・[HTMLモック](../mockups/analysis.html)・[FN-001](../../functions/FN-001-ランキング集計仕様.md)

アーティスト選択の下に組み合わせランキング（初期）と作家指定分析の2タブ。

## 組み合わせランキング

作詞 × 作曲の方向付きpair。FN-001の同一Song内の直積、Work重複排除、自己pair、順位規則を継承する。既存の作家候補選択と担当チェック（両OFFはOR、片方は指定側、両ONは同一作家の自己pair）、絞り込み後の順位再計算、解除を維持する。未選択は全件、選択時は自己pair件数と絞り込み条件を見せる。作詞者・作曲者は個別の作家詳細リンクにし、別の「共同制作楽曲」ボタンで根拠を開く。

根拠は既存のネイティブdialog、Escape、閉じるボタン、起点フォーカス復帰を活用する。根拠に作品名の詳細リンクと必要に応じ個別音源アンカーを追加する。現行のTabを常に閉じるボタンへ固定する処理は外し、ダイアログ内の全リンクをTab/Shift+Tabで操作できるようにする。自己pairの作品も表示する。

## 作家指定分析（新規・推奨定義）

公開楽曲JSONを読み込み、対象artistのprimary Songにクレジットされた全作家からIDで選択する。候補は正規名を検索でき、同名候補はIDで識別できる。作家詳細の「この作家を分析」から対象選択済みのURLで開く。未選択では選択案内を表示する。

- 担当作品数は対象作家が担当した異なるWork数（全役割）。既存allの担当曲数と一致する。
- 共同制作は、**同一Songに対象作家Aと別の作家Bが両方クレジットされること**。英語詞やブラス編曲を含む全役割を対象とし、同一役割の共担も含む。対象作家自身は相手から除外する。A・Bが異なるSongにしかいないWorkは除く。
- WorkごとにSongを走査し、creditsの作家IDを集合化する。AがいるSongのBについて `B → work_id → song_id集合` に追加。相手ごとの作品数はWork集合の大きさで、別Versionに同じ組があっても1件。すべての成立Song IDは根拠に保持する。相手の人数は相手IDの数。
- 相手ごとに作品数降順、同数はID昇順、競技順位。順位、作家詳細リンク、作品数、最多行に対する横棒、根拠ダイアログを表示する。根拠はWorkごとの作品名リンク、実際に共担した音源へのリンクを表示。Workは初出日昇順・不明末尾・同日はWork ID順。担当作品があって共同制作相手がいない場合も担当作品数は表示する。

例。W1のS1でAが作詞と作曲、Bが編曲。S2でAとBが再度参加し、S3にCのみが参加する場合、Aに対するBはW1の1作品（S1/S2を根拠）、Cは0、A自身は相手一覧の対象外。既存の作詞×作曲ランキングではS1のA×Aは成立する。作品の制作実態を断定せず、共通クレジットに基づく指標であることを説明する。
