# SCR-003 検索

[共通設計](../公開サイト共通設計.md)・[公開JSON設計](SCR-003-公開JSON設計.md)・[HTMLモック](../mockups/songs.html)

アーティスト選択の下に楽曲検索（既定）と作家検索の2タブ。各タブに検索欄、件数、横線区切りの一覧を表示する。初期の空検索では全件を表示する。

## 検索・並び替え確定仕様

- 楽曲検索はWork単位。作品名、掲載名義、作家の正規名をNFKC・小文字化して空白区切りのAND部分一致で検索する。音源名・読み仮名単独は現行の検索対象外。初出日（新しい順が既定／古い順）、曲名順（日本語照合）を保持する。同順位はWork ID順、日付不明は日付順の末尾。作品名からSCR-004へ遷移し、一覧の音源モーダルを置き換える。
- 作家検索はPR #119の全担当作家の正規名、NFKC・大文字小文字を区別しない部分一致、作家名の日本語照合順（同名はID順）、件数、作家名からSCR-006へのリンクを維持する。曲数順や作家ID検索は追加しない。
- タブ・検索条件・ソート・起点位置の復元、直接アクセス、状態表示は共通設計に従う。
