# SCR-002 その他・サイト情報

## 基本情報・機能概要
URL `/more/`。一般閲覧者向けのその他・サイト情報画面。PR #100の承認済み設計。PR #101でページを実装済み。モック項目は設計上の対応を示し、現行の実装境界は[検証記録](../../../history/reviews/public-site-pr1-validation.md)を参照する。

## 操作・データ参照・バリデーション・表示条件
免責事項と連絡先を初期公開に含める。Xは別タブで開きrel="noopener noreferrer"。フォーム・入力・バリデーション・データ通信は対象外。収録方針・収録状況・更新履歴は [SCR-009](SCR-009-データについて.md)へのリンクから開く。

## 状態・定数・表示文言
固定文言を表示する。

## 非機能仕様
共通仕様のナビ・safe-area・320px・フォーカス・読み上げ規則を適用。長い曲名・共同作家名を省略せず折り返す。作家カードは本文幅に応じ2列/1列。

## 対象外・未確定・引継ぎ
PR #101の実装範囲は上記検証記録を参照。
実装PR分割は暫定、設計レビュー後に最終判断。現行集計・FN-004・canonicalを変更しない。検証記録は[モックREADME](../mockups/README.md)。

アーティスト欄（C-08〜15）はPC/SPとも非表示でモックDOMにも置かない。タイトル→サイト概要→データについてへのリンク→免責→連絡先・Xの順。連絡先の見出しに #contact を設ける。本文と外部リンク仕様は維持。
