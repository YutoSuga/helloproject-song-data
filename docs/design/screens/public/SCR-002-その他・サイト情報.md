# SCR-002 その他・サイト情報

[共通設計](../公開サイト共通設計.md)・[HTMLモック](../mockups/more.html)

サイト名称と目的、非公式表記、収録方針・アーティスト別収録状況、集計方法、サイト更新履歴、免責事項・問い合わせを表示する。方針・収録状況・履歴の読み込みとセクション別の取得中/空/失敗表示は現行を引き継ぐ。問い合わせのXリンクは別タブ。アーティスト選択欄は置かず、他画面への共通ナビで選択状態を保持する。

集計方法（新設 `#aggregation-method`）ではprimary音源、Work重複排除、担当区分、同順位、同一音源での作詞×作曲、作家指定分析での共同制作の定義を説明する。作詞×作曲は役割と順序を持つ組み合わせで、分析のチェックONでは自己組み合わせも表示する。作家指定分析は同一音源の全役割（同役割の共担も含む）で別作家を数え、自己組み合わせを含めない。既存のアンカーは共通設計の移行表を参照。ホームには更新履歴を表示しない。
