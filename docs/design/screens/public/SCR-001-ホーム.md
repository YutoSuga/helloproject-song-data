# SCR-001 ホーム

[共通設計](../公開サイト共通設計.md)・[HTMLモック](../mockups/index.html)

1. キャッチコピー・サイト説明。
2. 共通アーティスト選択。
3. 集計サマリー。作品数は ranking.summary.target_work_count、音源数は ranking.summary.primary_song_count、作家数は categories.all.entries の作家数。いずれも選択artistの公開データを参照する。
4. 作家ランキング TOP3。categories.all.entries の rank ≤ 3 を既存順で表示。順位、作家名の詳細リンク、担当曲数、横棒、ランキング全体（all）へのリンク。
5. 組み合わせランキング TOP3。初期状態は「すべて」、切り替えで「作詞 × 作曲」（自己組み合わせなし）を表示する。各方式で再計算した rank ≤ 3 の全組を表示する。作家名は作家詳細、曲数はSCR-010、分析リンクは選択中の方式を引き継ぐ。
6. 楽曲検索・作家検索のショートカット。どちらも選択artistと明示タブを渡す。

同順位は3位以内にある全行を表示する。空カテゴリは空の案内、取得失敗はエラー。集計値は公開JSONから取得する。更新履歴はその他に置く。
