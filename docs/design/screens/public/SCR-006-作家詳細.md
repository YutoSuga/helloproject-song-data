# SCR-006 作家詳細

[SCR-005 作家一覧・ランキング](SCR-005-作家一覧・ランキング.md)の作家検索と曲数ランキングから共通の詳細ページへ遷移する。[HTMLモック](../mockups/creator-detail.html)の内容はレビュー用の仮値。

## URLと戻る操作

`/creators/detail/?creator_id=C00028&artist_id=G00001`。両IDを必須とし、公開対象のアーティストはJuice=Juice（G00001）。パラメータを保持した直接アクセス・再読み込みをサポートする。欠損や不正形式、未公開アーティストの場合は対象を表示できない旨を案内し、対象作家の行が存在しない場合は担当楽曲が見つからない旨を表示する。読込失敗も画面上に表示する。

一覧から渡される `view`・`category`・`q` を戻るリンクに引き継ぐ。元の履歴エントリも状態を保持するためブラウザの戻る操作で復元できる。状態を伴わない直接アクセスでは作家一覧の初期表示に戻る。

## 画面項目

| 項目 | 表示・操作 | データ参照元 |
| --- | --- | --- |
| 作家名・対象アーティスト名・総担当曲数 | 見出しと概要 | ランキングJSONの `artist` と `categories.all` |
| 順位と曲数 | すべて、作詞、作曲、作詞 & 作曲、編曲の順の閲覧専用表。該当がなければ順位なし・0曲 | ランキングJSONの各カテゴリの該当作家行 |
| 担当楽曲 | Workごとに作品名とその作家の全担当役割。複数Songを持つ作品も1行 | `categories.all.entries[].works` |
| 絞り込み | すべて（初期）、作詞、作曲、編曲、その他。0件の案内あり | Workの `roles` |
| 戻る | 遷移元の一覧状態に復帰 | URLの一覧状態 |

作品の初出日は対象アーティストの楽曲一覧JSONと `work_id` で対応づけ、`first_release_date`（対象アーティストのprimary音源における既知の最小リリース日）を使用する。初出日の昇順、欠損は末尾、同日・欠損同士はWork IDの昇順とする。

「その他」は作詞・作曲・編曲以外の担当役割が一つでもある作品を含む。各絞り込みは独立し、複数条件を満たす作品はそれぞれの結果に表示する。絞り込み後も日付順と担当作家の全バッジを保持する。既知の役割は作詞、作曲、編曲、英語詞、ブラス編曲の順とし、新しい役割のラベルが未定義の場合は役割IDを表示する。

順位・集計根拠・初出日は既存の公開JSONを再利用する。組み合わせランキングの根拠はSCR-005の既存モーダルで表示する。
