# SCR-006 作家詳細

[検索](SCR-003-楽曲一覧・検索.md)、[ランキング](SCR-005-作家一覧・ランキング.md)、ホーム、楽曲詳細、分析から到達する。[HTMLモック](../mockups/creator-detail.html)の内容はレビュー用の仮値。

## URLと戻る操作

`/creators/detail/?creator_id=C00028&artist_id=G00001`。両IDが必須。状態・エラー・旧リンクの扱いは[共通設計](../公開サイト共通設計.md)。担当楽曲名からSCR-004へ。「この作家を分析する」でSCR-009の作家指定分析を選択済みで開く。

## 画面項目

| 項目 | 表示・操作 | データ参照元 |
| --- | --- | --- |
| 作家名・対象アーティスト名・総担当曲数 | 見出しと概要 | ランキングJSONの `artist` と `categories.all` |
| 順位と曲数 | すべて、作詞、作曲、作詞 & 作曲、編曲の順の閲覧専用表。該当がなければ順位欄に「ー」、曲数欄に「0曲」 | ランキングJSONの各カテゴリの該当作家行 |
| 担当楽曲 | Workごとに作品名とその作家の全担当役割。作品名は楽曲詳細へのリンク。複数Songを持つ作品も1行 | `categories.all.entries[].works` |
| 絞り込み | すべて（初期）、作詞、作曲、編曲、その他。0件の案内あり | Workの `roles` |
| 戻る | 左向きシェブロン付きのアクセント色リンク。高さ44px以上を確保し、SPでは共通ヘッダーと本文の間に16pxの余白を取る。遷移元の一覧状態に復帰 | URLの一覧状態 |

作品の初出日は対象アーティストの楽曲一覧JSONと `work_id` で対応づけ、`first_release_date`（対象アーティストのprimary音源における既知の最小リリース日）を使用する。初出日の昇順、欠損は末尾、同日・欠損同士はWork IDの昇順とする。

「その他」は作詞・作曲・編曲以外の担当役割が一つでもある作品を含む。各絞り込みは独立し、複数条件を満たす作品はそれぞれの結果に表示する。絞り込み後も日付順と担当作家の全バッジを保持する。既知の役割は作詞、作曲、編曲、英語詞、ブラス編曲の順とし、新しい役割のラベルが未定義の場合は役割IDを表示する。

順位・集計根拠・初出日は既存の公開JSONを再利用する。対象アーティストは名前のみを表示する。

## 共同制作者 TOP3

SCR-009と同じ全担当区分の集計を用い、競技順位が3位以内の行をすべて表示する。名前は作家詳細、曲数はSCR-010、0件は「共同制作楽曲はありません。」。「この作家を分析する」は共同制作者欄の下に1か所だけ置く。PCは順位表と共同制作者欄を同じ高さから左右に並べ、SPでは順位表、共同制作者欄、分析リンクの順に縦に並べる。担当楽曲一覧は両版とも全幅。

## 共同制作者からの遷移

共同制作者TOP3の表示順位とリンクは共同制作集計に従う。遷移先の共同制作楽曲詳細では2人の作家名を共通順で表示する。
