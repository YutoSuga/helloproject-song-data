# SCR-010 共同制作楽曲

[モック](../mockups/collaboration-detail.html)を参照。分析の詳細として、共通ナビに分析の現在位置を表示する。ホーム・組み合わせランキングの両方式・作家指定分析・作家詳細の曲数リンクから遷移する。

## URLと状態

`/analysis/detail/?artist_id=G00001&creator_id=C00001&partner_id=C00002`。異なる2人はID昇順に正規化し、逆順でも同じ結果を表示する。直接アクセス・リロードをサポートする。戻り先は[共通設計](../公開サイト共通設計.md)に従い、遷移元がなければ分析。IDの形式、不明の作家、公開対象外のアーティストはメッセージで区別する。作家は存在するが共担がない場合は0曲と空の案内を表示する。

## 表示

戻るリンク、見出し、アーティスト名、作家詳細へリンクする2人の名前、総曲数、担当区分別内訳、共同制作楽曲一覧、共通フッターの順。異なる2人は遷移元にかかわらず全担当区分を表示する。方向付きランキングの曲数とは異なる場合がある。「すべて」「作詞×作曲」の切り替えは置かない。同一IDは本人が同じSongで作詞と作曲を両担当したWorkに限り、既存の作詞×作曲ランキングの根拠と曲数を使用する。

## 内訳と作品一覧

全担当区分は[分析の共通集計](SCR-009-分析.md)から取得する。同じSongで成立した2人の担当区分を、作家IDにひも付けた役割のペアとして保持する。各パターンをWork単位で数え、1曲以上だけを表示する。複数パターンに該当するWorkがあるため内訳の合計が総曲数と異なり得る旨を表示する。

順序は作詞×作曲、作詞×編曲、作曲×編曲、同一の通常役割（作詞、作曲、編曲）、その他を含む役割。その他の組は各役割を作詞、作曲、編曲、英語詞、ブラス編曲の順に置いた小さい側・大きい側の組で比較する。同じ役割の組では作家ID昇順、異なる役割の組の担当方向は若い作家IDに割り当たる役割順で表示する。内訳は情報表示のみ。

作品は初出日昇順、不明末尾・同日はWork ID昇順。Workは1行、楽曲詳細へのリンクと、そのWorkのSongで成立したパターンを個別に表示する。根拠のSong IDは集計に保持し、利用者には楽曲詳細のクレジットを案内する。
