# 公開サイト共通設計

## 現在の画面（実装済み）

現在の公開対象は Juice=Juice（`G00001`）。画面は[FN-001 が生成した JSON](../functions/FN-001-公開サイトデータ生成.md#入力と出力)を読み込む。

- 入力：FN-001がcanonical CSVから生成した公開用JSON。
- 表示：`site/` のHTML・CSS・JavaScriptをブラウザで実行する。`site/app.js` が生成済みJSONを読み、ランキングと作詞 × 作曲の組み合わせ分析を表示する。
- ブラウザではCSVからランキングを集計せず、生成済みJSONを表示する。

作詞者・作曲者の組み合わせ分析の集計と、creator 起点表示の絞り込み・順位の規則は[ランキング集計仕様](../functions/FN-001-ランキング集計仕様.md)を参照する。生成と公開の流れは[FN-001](../functions/FN-001-公開サイトデータ生成.md#build公開の運用)を参照する。

## 今後の画面構成

[機能ID体系の公開サイト画面一覧](../system/機能ID体系.md#公開サイトの画面番号)を参照する。旧SCR-001は現行サイト全体を指していた。現行のランキングはSCR-005 作家一覧・ランキングへの移行を予定する。SCR-001 ホームを含む個別画面の項目・操作・遷移は、今後のUI改修で整理する。
